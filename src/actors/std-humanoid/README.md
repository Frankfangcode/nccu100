# 政大標準人形（std-humanoid，試做）

一套骨架、一個身體、一組動作，主角和 NPC 共用；造型靠調色盤換色和掛在骨頭上的配件區分。
目的是之後加一件衣服或一個動作，所有角色都能用，不必每個角色各自建模。

## 怎麼開

| 網址參數 | 效果 |
| --- | --- |
| `?newplayer` | 主角換成標準人形 |
| `?campuslook` | 路上的學生（`npcs.json` 的 `students`）換成標準人形，每人配色、配件不同 |

兩個可以一起用。不加參數時不下載模型、不建立任何物件，遊戲行為不變。

## 骨架規格（22 根，命名照 Mixamo 慣例，不加 `mixamorig:` 前綴）

```
Hips ─ Spine ─ Spine1 ─ Spine2 ─ Neck ─ Head
 │                        ├ LeftShoulder ─ LeftArm ─ LeftForeArm ─ LeftHand
 │                        └ RightShoulder ─ RightArm ─ RightForeArm ─ RightHand
 ├ LeftUpLeg ─ LeftLeg ─ LeftFoot ─ LeftToeBase
 └ RightUpLeg ─ RightLeg ─ RightFoot ─ RightToeBase
```

- 靜止姿勢是 A 字站姿，模型高 1 公尺、面向 +z，進遊戲放大 1.3 倍，頭骨再放大 1.15 倍（Q 版比例）。
- `Head` 骨頭空間：+y 往上、+z 是臉的正面，配件用這個座標。
- 之後新做的衣服、髮型零件，只要綁在同名骨頭上就能共用所有動作。

## 動作

`humanoid.glb` 內含四個片段：`Idle`、`Walk`、`Run`、`Wave`（在 Blender 用程式產生，有手肘與膝蓋）。
遊戲裡依角色**實際移動速度**混合待機、走路、跑步，播放速度跟著移動速度變，所以不用改任何移動邏輯。

舊邏輯擺出特殊姿勢時仍然有效：舊關節手臂抬高（拿東西、撐傘、驚慌）或主角騰空時，手臂與腿改跟舊關節的角度。

因為骨頭名稱照 Mixamo 慣例，之後可以把外部動作庫的片段重新對應進來；這次沒有引入任何外部動作檔。

## 造型（`looks.js`）

- `BASE_PALETTE`：模型貼圖各部位用到的顏色，每組第一個是本色，其餘是陰影或亮部（頭髮、上衣、褲子、書包、膚色）。
- `campusLook(seed)`：用編號產生固定造型（上衣、褲子、髮色、膚色、書包顏色與配件），同一個編號每次結果一樣。
- 換色做法：載入後把貼圖畫到 canvas，逐一把本色換成目標色，陰影與亮部依原本明暗比例跟著變；相同造型共用同一張貼圖。
- 配件目前有眼鏡、耳機，用 `toon()` 材質掛在 `Head` 骨頭上。

## 目前的限制

- 身體只有一個（帽 T、長褲、後背包、刺蝟頭）。**衣服版型、髮型還不能換**，只能換顏色與加配件；要換版型得在 Blender 做出綁同一套骨架的零件，這是下一步。
- 學生的臉都一樣；驚慌、眨眼表情在標準人形上沒有作用（舊模型是換臉部貼圖）。
- 角色換裝、角色卡預覽仍作用在舊模型的零件上，標準人形看不到。
- 游泳裝與雄鷹形態沒有新造型，主角會自動切回舊模型。
- 有具名的 NPC（校長、學務長等）沒有換，維持原樣。

## 實作上要知道的事

- 為了在所有場景（含室內）畫面算出前更新骨頭，啟用時會包一層 `renderer.render`；不加參數時不會包。
- 描邊用法線外推（蒙皮網格不能用 `outline()` 的縮放法），顏色 `#2a2c4a`，寬約 0.01 公尺。
- 模型用 gltfpack 壓縮（meshopt 與量化），UV 靠貼圖的位移與縮放還原，換色產生的新貼圖必須照抄這些設定。
- 離鏡頭超過 70 公尺或被隱藏的角色不更新動作。

## 模型怎麼來的

設定圖 → Tripo（免費版 H2.5）生成 → 重拓撲約 8000 面 → Blender 處理貼圖、建骨架、自動權重、產生動作 → gltfpack。整個檔案約 282 KB。

貼圖的做法（v2.10 定稿）：

1. 頭髮與膚色由 Frank 在 Blender 手繪定色，再用程式把筆刷的雜色吸回色票。
2. 衣服、褲子、書包、鞋子：沿模型表面做多數決，去掉 AI 貼圖的雜點並把邊界修順，每區一個本色；下襬白色內搭依高度修成整齊的一圈。
3. 陰影：用 Cycles 烘出環境遮蔽與法線，取照不到光的地方換成各區的陰影色（兩階、無漸層，光源在上方，角色轉向時不會穿幫）。
4. 存成 21 色的調色盤 PNG。
